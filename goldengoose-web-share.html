SECTION 07

DAU 고도화 기능 우선순위

인수 후 홈 화면 구조와 수익 기반을 기준으로 우선순위를 재정의했습니다. P1은 수익 기반 최적화, P2~P5는 재방문과 신뢰를 강화하는 홈 중심 기능입니다.

P1
미디에이션 최적화
인수 후 가장 먼저 손봐야 할 과제입니다. 보상형 광고, 전면 광고, 오퍼월 유입을 미디에이션 기준으로 다시 조정해 광고 단가와 완주율을 함께 최적화합니다. 초기 참여 구간은 짧은 광고로 진입장벽을 낮추고, 고수익 구간은 보상형 광고를 집중 배치해 수익성과 이탈률을 동시에 관리하는 방향입니다.

SECTION 08

홈 화면 구조 및 신규 기능 배치

제공해주신 홈 화면 기준으로 현재 구조를 재정리하고, 미디에이션 최적화 이후 어떤 기능을 어디에 붙여야 자연스러운지 정리했습니다.

홈은 이미 단순하고 강합니다 — 그래서 신규 기능도 가볍게 붙어야 합니다
현재 황금거위 홈은 거위 클릭, 주간 완주형 보상, 순금 응모, 미니게임, 오퍼월, 친구초대 중심의 참여형 구조입니다.
따라서 신규 기능은 무거운 커뮤니티보다 수익 최적화 → 추가 진입 포인트 → 주간 완주율 강화 → 경량 정보 기능 순으로 붙는 것이 자연스럽습니다.
FUNCTION SPEC
상단 상태 영역
응모권, 캐시, 출금 버튼을 상단에 고정 노출합니다.
현재 참여 시간은 9시 → 12시 → 18시 흐름으로 표시하고, 현재 시간대 기준으로 남은 황금알 / 참여 가능한 황금알을 함께 보여줍니다.
PUSH TRIGGER
시간대별 재진입 푸시
매일 특정 시간에 황금알이 생성되었다는 푸시를 발송해 유저가 다시 앱에 들어오게 만듭니다.
핵심은 9시, 12시, 18시 같은 참여 가능 시간대를 명확히 각인시켜 정해진 시간에 반복 접속하는 습관을 만드는 것입니다.
GOOSE CLICK
거위 클릭 기본 루프
황금알은 9시, 12시, 18시에 자동 지급되며, 하루 최대 10개까지 받을 수 있습니다.
유저는 거위를 클릭해 황금알을 열고 참여하며, 10번 모두 참여 완료 시 응모권이 지급됩니다.
WEEKLY LOOP
주간 미션 참여 보상
1일차 모두 참여 시 응모권 1개 지급
3일차까지 모두 참여 시 응모권 2개 지급
5일차까지 모두 참여 시 보너스 캐시 200 지급
7일차까지 모두 참여 시 응모권 5개 + 보너스 캐시 200 지급
이 구조는 단순 출석체크가 아니라 주간 완주형 보상 루프로 해석하는 것이 적절합니다.
BONUS CASH
보너스 캐시(쿠팡) 동작
각 시간대별 황금알을 모두 열었을 때 보너스 캐시가 등장합니다.
유저가 해당 영역을 선택하면 쿠팡 참여 페이지로 이동하며, 기존 거위 클릭이나 주간 미션과 분리된 별도 보상 액션으로 설계합니다.
GOLDEN RANKING
황금순위 운영 정보
매주 금요일 9시 회차별 결과를 발표하며, 24K 0.1g 당첨 정보를 노출합니다.
전체 누적 지급 현황, 내 이번 주 순위, 최근 황금 당첨 후기를 함께 보여줘 순금 응모 전 신뢰와 기대를 강화합니다.
MINI GAME
미니게임 구성
가볍게 참여할 수 있는 가위바위보, 순발력 테스트, 룰렛, 사다리 타기 등을 구성합니다.
짧은 플레이타임 안에 바로 참여와 보상이 이어지도록 설계해, 홈 진입 후 추가 참여율과 재방문 빈도를 높이는 역할을 합니다.
REVIEW & PROMOTION
리뷰 및 홍보 보상
친구에게 알림톡으로 코드를 보내 가입 후 참여까지 완료한 경우 500캐시를 즉시 지급합니다.
앱 리뷰 작성이 확인되면 100캐시를 지급합니다.
레퍼럴과 리뷰 보상은 별도 홍보 축으로 운영해 신규 유입과 신뢰 강화를 동시에 유도합니다.

RE-ENGAGEMENT

MINI GAME POPUP

광고 후 대기 구간 설계
중요한 점은 유저가 광고를 본 뒤 어느 정도 대기 후 다시 광고를 보게 만드는 장치가 필요하다는 것입니다.
황금알이 다시 열릴 때까지의 시간을 단순 대기 시간이 아니라, 보너스 캐시, 황금순위, 응모권 현황, 다음 보상까지 남은 시간을 확인하게 하고 다음 시청까지 시간을 확보하는 구간으로 설계해야 합니다.
미니게임 하단 팝업 유도
1일차 참여 또는 해당 시간대 참여가 모두 종료되면 하단 팝업으로 미니게임 참여를 유도합니다.
금고 열기, 순발력 테스트, 룰렛, 사다리 타기 같은 저마찰 액션으로 광고와 광고 사이를 메우고, 앱 내 참여 시간을 높여 계속 참여시키는 구조로 DAU를 끌어올리는 것이 핵심입니다.
